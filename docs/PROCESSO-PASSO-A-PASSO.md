# SENTINELA BRASIL · fluxo passo a passo

API demonstrativa para governança, acesso e auditoria de dados.

## 1. RECEBER REQUISIÇÃO

Enviar solicitação à API FastAPI com identidade e finalidade.

## 2. AVALIAR POLÍTICA

Verificar permissões e regras de acesso configuradas.

## 3. PROTEGER SEGREDO

Usar o vault local demonstrativo para material sensível de teste.

## 4. REGISTRAR EVENTO

Adicionar evento à trilha de auditoria e verificar integridade.

## 5. RETORNAR DECISÃO

Exibir autorização ou bloqueio com motivo rastreável.

## Resultado e limites

Demonstração local. Requer hardening, autenticação real, gestão de chaves e revisão antes de produção.
