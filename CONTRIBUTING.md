# Como contribuir

1. Leia `README.md`, `SECURITY.md` e `docs/threat-model/THREAT_MODEL.md`.
2. Abra uma issue descrevendo problema, motivação, impacto defensivo e alternativa considerada.
3. Envie uma pull request pequena, com testes automatizados e documentação atualizada. Use apenas fixtures e exemplos sintéticos.
4. Não inclua segredos, dumps de produção, dados pessoais, conteúdo governamental restrito ou código de terceiros sem confirmar compatibilidade de licença.
5. Execute `ruff check .` e `pytest` antes de enviar. Mudanças de segurança precisam incluir testes negativos.

Contribuições são licenciadas sob Apache-2.0, conforme a licença do repositório. A aceitação não implica endosso institucional.
