# Código de Conduta

Esperamos interações respeitosas, construtivas e inclusivas. Seja cordial, considere perspectivas diferentes e concentre feedback no trabalho, não na pessoa. Assédio, discriminação, intimidação, doxxing, ameaças e divulgação de dados privados não são aceitos.

Mantenedores podem remover conteúdo inadequado e restringir participação proporcionalmente. Para reportar uma situação, contate os mantenedores por canal privado indicado no perfil do repositório. A equipe buscará preservar a confidencialidade e responder com imparcialidade.

Este código adapta os princípios do Contributor Covenant, versão 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
